---
description: How to review a code change before answering with feedback.
metadata:
  audience: reviewers
---
When the user asks for a code review:

1. Read the whole change before commenting on any line.
2. Lead with correctness problems, then security, then performance, then style.
3. For every finding, quote the exact lines and explain the consequence.
4. Finish with a one-line verdict: approve, approve with nits, or request changes.
